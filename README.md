# psm-demo
This is a Python project for me to learn how to use `pyspacemouse` and `blessed`. It reads values from `spacemouse.read()` and displays it in a TUI with `blessed`.
## Usage
uv is needed to run this project. Get it from [here](https://docs.astral.sh/uv/getting-started/installation/).

To run this project, run `uv run main.py` in the project root.
